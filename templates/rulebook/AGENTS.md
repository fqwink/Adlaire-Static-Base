# プロジェクト名 - 最上位ルールブックテンプレート

## 0. 絶対原則

`AGENTS.md` は、本リポジトリにおける最上位ルールブックである。

このテンプレートを使用する場合は、対象リポジトリの仕様正本、生成物、Git運用、承認ルールに合わせて必ず調整する。

テンプレートのまま運用してはならない。

## 1. 承認ルール

`templates/rulebook/approval-rule.md` を参照して、対象リポジトリの承認ルールを記載する。

## 2. 仕様書管理ルール

`templates/rulebook/spec-management-rule.md` を参照して、対象リポジトリの仕様正本と生成物の関係を記載する。

## 3. Git 運用ルール

`templates/rulebook/git-rule.md` を参照して、対象リポジトリのbranch、Pull Request、merge、削除ルールを記載する。

## 4. テンプレート運用ルール

`templates/rulebook/template-rule.md` を参照して、テンプレートの正本性、使用範囲、更新ルールを記載する。
